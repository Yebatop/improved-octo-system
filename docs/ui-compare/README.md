# UI: макет против игры

Каждый файл `<экран>.png` — макет слева, игра справа. Окно 1280×720, масштаб интерфейса 2, язык русский.
Экраны сняты в реальной игре на локальном сервере 1.21.11 со вторым клиентом (Bob): настоящий бой, смерть, повтор и убийство.
Мокапы отрендерены из артефакта в Chromium с градационным (не LCD) сглаживанием, чтобы сравнение было честным.

| Файл | Экран |
|---|---|
| `menu.png` | Меню мода, страница KillCam |
| `hud.png` | HUD в бою: плашка ClanShare, «Бой», карточка цели, KillCam, счёт сессии |
| `killcam.png` | Повтор KillCam на скорости 0,5× |
| `killcard.png`, `killcard@2x.png` | PNG-карточка с данными из макета, 800×420 и 1600×840 (рендер из `KillCardRenderTest`) |
| `killcard-real.png` | Карточка реального убийства в игре (настоящие лица из скинов) |
| `tokens.png` | Отладочный экран `/skirmish theme` против артборда «Токены темы» |
| `extra-*.png` | Экраны без макета, собранные из того же кита: редактор HUD, экран смерти, наковальня, список меток, превью карточки |

## Оставшиеся расхождения

### Меню
- За окном виден мир и HUD, а в макете — ровный фон. Затемнение то же (`backdrop`).
- У KillCam настроек больше, чем четыре строки макета. Первые четыре совпадают с макетом, остальные уходят в прокрутку (справа видна полоса).
- В списке модулей есть ещё «Метки» и «Интерфейс» (цвет акцента и расположение HUD). В макете их нет.
- Текст — см. «Ограничения движка» ниже: строка может отличаться по ширине на 1–2 px, а мелкий серый текст чуть светлее.

### HUD
- Данные живые: Bob вместо GFk31AK, пинг 1 мс на локальном сервере, другие числа. Размеры, отступы, цвета и места совпадают.
- Вместо заглушки «[скин]» — настоящее лицо из скина, вместо цветных квадратиков — иконки предметов.
- Прицел и хотбар — ванильные: они часть игры, а не мода.

### KillCam
- Вместо заглушки мира — настоящий повтор с камеры убийцы. Подпись макета «[повтор: вид со стороны]» не переносилась: на этом месте появляются подсказки камеры («убийца вне радиуса записи», управление свободной камерой).
- Число и места меток зависят от записанного боя.
- Старая строка-шпаргалка с горячими клавишами убрана (в макете её нет). Клавиши работают как раньше: пробел/P, ←/→, ↑/↓, 1–3, C, R, Esc.

### KillCard
- Java2D рисует немного иначе, чем Chromium: отличия заметны только в антиалиасинге отдельных пикселей глифов.
- Плитки снаряжения показывают иконки предметов на фоне `tile`, а не цветные квадраты-заглушки.

### Токены
- Отличается только сглаживание текста (см. ниже).

## Ограничения движка (точнее не воспроизвести)
1. **Позиционирование глифов.** В Minecraft нет кернинга и субпиксельного позиционирования TTF, а атлас шрифта семплируется NEAREST. Поэтому каждый глиф ставится на целый пиксель (опережения округлены). Без этого тонкие штрихи пропадали, а у браузера позиции дробные. Итог — ±1 px между буквами.
2. **Толщина мелкого текста.** Браузер (Skia) усиливает покрытие светлого текста на тёмном. Это повторено гамма-коррекцией покрытия глифов (`font.coverage_gamma` = 1.45, подобрана по сравнению «чернил» на скриншотах), но только для наших шрифтов. На 11 px серый текст всё равно выглядит чуть тоньше.
3. **Чёткость только при масштабе 2.** TTF-шрифты растеризуются в «дизайн-пикселях» (1 px макета = 1 физический px при масштабе 2). При другом масштабе интерфейса они масштабируются NEAREST и выглядят грубее, хотя фигуры (SDF) остаются чёткими при любом масштабе.
4. **Скругление картинок.** GUI-пайплайн текстур не умеет маску со скруглением. Лицо в карточке цели и миниатюра карточки скругляются маской цвета панели поверх углов, а не настоящим клипом. Сама PNG-карточка скругляет лица честно (Java2D).
5. **Клип прокручиваемых списков.** Scissor работает в целых GUI-пикселях, то есть с точностью 2 px макета.
6. **Хинтинг.** Шрифты грузятся без хинтинга (FreeType `NO_HINTING`) через render-only миксин. Иначе FreeType подгоняет штрихи под пиксели, а браузер так не делает.

## Как пересобрать сравнение
- Мокапы: HTML-артборды из артефакта, Chromium 1280×720 с `--disable-lcd-text --font-render-hinting=none`.
- Игра: `./gradlew runClient --args="--width 1280 --height 720"`, `guiScale:2`, клики через xdotool.
- Карточка: `./gradlew test` пишет `build/killcard-test/killcard_mockup*.png`.
